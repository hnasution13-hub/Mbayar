Cara Backup:

  2. Klik "Export All Data"
  3. Simpan file ZIP yang didownload
Cara Restore:
  1. Pilih file ZIP hasil backup
  2. Ceklis "Hapus data yang ada" jika ingin bersihkan database

  4. Tunggu proses selesai
